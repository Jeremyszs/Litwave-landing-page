Asynchronous Lifecycle Decoupling

Litwave isolates Starlette routing from physical audio and MIDI hardware. Audio streams and worker threads initialize only during `AppState.boot()`.

SubsystemTechnologyPurpose
Backend ServerStarlette / UvicornAsynchronous REST API & WebSocket bus
Audio DriverMiniaudio / SounddeviceNative low-latency practice playback
MIDI CoreMido Worker ThreadDedicated background event loop (1:1 passthrough)
