# Litwave Landing Page

Official web prototype and landing page artifact for **Litwave — Practice Workstation for Keyboardists**.

- Built with Open Design Pitch Black tokens (`--bg: #000000`, studio cyan `#38bdf8`, Geist typography).
- Fluid morphing liquid-glass navigation header with click-toggle dropdown.
- Dual-surface practice architecture previews (Desktop Studio View & Mobile Stage Remote).
- Real-time interactive 8-pad MPC sound lab and analog 3-oscillator worship drone with oscilloscope.
- Direct download links for the portable Windows release (`v0.1.0`).

## Local Preview
Open `index.html` directly in any modern browser, or serve via any static file server:
```bash
npx serve .
```
