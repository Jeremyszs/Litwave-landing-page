# Litwave Landing Page

Static landing page for **Litwave — Practice Workstation for Keyboardists**.

The design reuses the app's own tokens (matte `#090a0c` panels, studio cyan `#38bdf8`, Geist and Geist Mono, 6px studio panels, rectangular faders, MPC pad palette), so the page feels like the app.

- `index.html`, `styles.css`, `app.js`: no build step, no dependencies.
- Live recreation of the studio (A–B loop, Nashville chords, mixer meters).
- Interactive chord demo, 48 FX pads in six banks (A–F), ambient drone with oscilloscope, and a five-page stage remote preview.
- `samples/` holds the short preview sounds used by some pads (generated by `make_synth.py`); other pads use a synthesized stand-in.
- Download links point to the latest Windows release (installer and portable zip).

## Local Preview

npx serve .
